ABOUT THE SERVER

О сервере

Preserved Realm — полуванильный сервер Minecraft Java Edition, где основное внимание уделяется самому выживанию, исследованию мира и событиям сообщества.

Полуванилла

Базовый опыт Minecraft с некоторыми дополнительными возможностями.

Без экономики

На сервере нет игровой экономики.

Без телепортаций

Нет регионов, /tpa, /rtp, телепорта на спавн и подобных команд.

Ивенты и дополнительные фишки

На сервере проводятся ивенты и присутствуют некоторые дополнительные особенности. Подробности будут опубликованы здесь по мере подготовки официального описания.
