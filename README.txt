PRESERVED REALM — сайт Minecraft Java Edition

Файлы:
- index.html — главная страница
- about.html — информация о сервере
- rules.html — правила из файла pravila_minecraft_server.txt, если он был доступен при сборке
- news.html — новости (пока без вымышленных публикаций)

2. Откройте index.html в браузере.
3. Для публикации загрузите все файлы в одну папку на веб-хостинге.
